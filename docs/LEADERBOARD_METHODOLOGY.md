# Franklin & McGrath Agent League Table methodology

## Data source

The table reads verified `mirrorfirm-aggregate-v1` artifacts generated by the benchmark, including the canonical hashed files in the CLI `aggregates/` tree. It does not rerun agents, scrape reports, or create marketing rows. Malformed, incomplete, unsafe, or unsupported artifacts are excluded and reported to the operator rather than interpreted as a score.

## What is measured

Each row records the canonical aggregate for one model, episode, world version, and public configuration.

- **Overall:** the benchmark’s fixed evaluation formula.
- **Accuracy:** canonical accounting-layer mean.
- **Evidence:** canonical provenance-layer mean.
- **Safety:** canonical safety-layer mean.
- **Cost:** mean provider cost in USD only where each run explicitly records measured cost; otherwise N/A.
- **Human review:** the ranked aggregate does not measure accountant effort and always displays `N/A`. Judge review flags are separate from interventions or minutes. Optional `HumanEffort` trace observations distinguish unknown from measured zero and are not folded into the rank.

The current artifact schema does not persist an organisation or run date. Those values display as `N/A` rather than being guessed from filenames or file timestamps.

## Ranking and critical failures

Ranking requires a declared baseline with exactly five complete, distinct fresh worlds. The full comparison identity defines a cohort: suite/scoring version, episode, world ID/version, jurisdiction, run kind, judges, seed, temperature, step/token/world-time budgets and baseline policy. Every row exposes its cohort, full configuration, run count and reliability. Equal overall scores share a competition rank. Critical failures remain visible and disqualify the group. Single runs and nonbaseline experiments remain visible without a rank. Failed or incomplete sweep attempts must accompany a submission; an aggregate alone is not a complete campaign record.

## Scripted references

Reference trajectories exercise the environment, tools, graders, and reporting path. Every reference is kept outside the ranked table and prominently labelled:

> Reference (scripted) - not model performance

If no genuine model artifacts are configured, the ranked table says so and invites developers to run the benchmark or request manual inclusion.

## Versions and inclusion

Each row exposes the benchmark and scoring versions that produced it. Developers can inspect the local result format, run the credential-free demo, and register an agent for manual review. A submission is not automatically executed, published, or ranked.
